# Christmas Shop

**Демо:** https://artkoro94.github.io/christmas-shop/

Интернет-магазин новогодних подарков. Проект создан на HTML, CSS и TypeScript с использованием Vite.

## Возможности

- Главная страница с описанием проекта и подборкой подарков.
- Каталог подарков с фильтрацией по категориям.
- Карточки подарков с подробной информацией в модальном окне.
- Переключение языка интерфейса.
- Адаптивная вёрстка для мобильных устройств и компьютеров.

## Технологии

- HTML5
- CSS3
- TypeScript
- Vite

## Запуск проекта

Требуется Node.js 20.19+ или 22.12+.

Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/artkoro94/christmas-shop.git
cd christmas-shop
```

Установите зависимости:

```bash
npm install
```

Запустите проект в режиме разработки:

```bash
npm run dev
```

Откройте адрес, который Vite выведет в терминале.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запуск локального сервера |
| `npm run build` | Сборка проекта в папку `dist` |
| `npm run preview` | Просмотр production-сборки |
| `npm run check` | Проверка TypeScript |
| `npm run lint` | Проверка кода ESLint |
| `npm run format` | Форматирование кода |
